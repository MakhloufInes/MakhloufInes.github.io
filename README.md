# Portfolio — Ines Makhlouf

Site statique (HTML, CSS, JavaScript), sans framework ni dépendance.

- `index.html` : contenu
- `style.css` : styles (mode clair et sombre)
- `script.js` : animation K-Means du hero
- `assets/` : CV (PDF) et portrait

## Voir en local

Ouvrir `index.html` dans un navigateur, ou lancer `python3 -m http.server` dans ce dossier.

## Mettre à jour le CV

Remplacer `assets/Ines_Makhlouf_CV.pdf` par la nouvelle version, en gardant le même nom.

## Déployer sur GitHub Pages

Pousser ce dossier dans un dépôt nommé `MakhloufInes.github.io`, puis activer Pages
(Settings → Pages → branche `main`, dossier `/`). Le site sera visible sur
https://makhloufines.github.io.
